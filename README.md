# 🛠️ C++ Small & Medium Projects Archive

Welcome to my dedicated space for small and medium-sized applications! This repository serves as a practical portfolio showcasing the transition from problem-solving logic to building fully functioning, modular, and maintainable software architecture using **C++**.

The core philosophy behind these projects is moving away from monolithic coding toward the **Divide and Conquer** paradigm—breaking down complex system requirements into clean, decoupled functions and reusable logic.

---

## 🚀 Core Engineering Principles Applied

* **Modular Design:** Code is organized into dedicated functions where each logical block has a single, clear responsibility (**Single Responsibility Principle** concept).
* **Clean & Readable Code:** Self-explanatory naming conventions, meaningful comments, and strict structural organization.
* **Robust Input Validation:** Handling edge cases, user errors, and data type verification to ensure application stability.
* **Logic Optimization:** Applying efficient algorithms developed through intensive problem-solving camps.

## 📁 Projects Registry

### 1️⃣ Project 1: Stone, Paper, Scissors (حجرة، ورقة، مقص)
A CLI-based game implementing game-loop structures, randomization logic, and interactive state management.
* **Key Highlights:** Refactored from a unified main function into independent modular functions handling round logic, computer AI simulation, and final score calculations.
* **Key Concepts:** Random number generation, conditional state handling, enum formatting.

### 2️⃣ Project 2: Math Game (لعبة التحديات الحسابية)
An educational mathematical game designed to test computational speed and logical correctness across various difficulty levels.
* **Key Highlights:** Utilizes modular logic to dynamically generate arithmetic questions based on user preferences (Add, Sub, Mul, Div, or Mix) and track performance metrics.
* **Key Concepts:** Advanced math logic customization, dynamic text/data manipulation, game state statistics tracking.
